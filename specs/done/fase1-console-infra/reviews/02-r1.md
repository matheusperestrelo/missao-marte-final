## Sugestões

1. `fases/fase-01-refatoracao/src/missaomarte/console/JogoConsole.java:146`: a condição `recorde.get().pontuacao() > 0` repete no console a guarda `recorde > 0` da Fase 0. Hoje o resultado é o mesmo, porque o `RankingTop5.registrar` só aceita pontuação positiva. Mesmo assim, é um pedaço da regra do recorde fora da `application` (R5.2). Uma opção é um método na `RankingTop5` (ex.: `recordeASerBatido()`, que devolve `Optional` vazio quando não há recorde positivo), para o console só decidir o que imprimir. Isso toca a `application`, então ficaria para uma tarefa futura, se o usuário quiser.
2. `fases/fase-01-refatoracao/src/missaomarte/console/JogoConsole.java:155-157`: `entrou = true` no `catch` supõe que `registrar` só lança a exceção depois de decidir que a entrada entra no Top 5. Um comentário de uma linha explicando a suposição evitaria que uma mudança futura no `registrar` produzisse um "Parabéns" indevido sem ninguém perceber.
