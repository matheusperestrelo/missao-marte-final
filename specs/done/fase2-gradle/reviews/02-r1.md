## Sugestões

1. `fases/fase-02-gradle/scripts/comparar-hash.sh:35` — o hash é impresso
   cortado em 12 caracteres (`${a:0:12}`). R4.2 pede "o hash SHA-256"; a
   comparação (linha 29) usa o hash completo, então a prova vale. Imprimir o
   hash inteiro deixaria a saída literal ao critério. Já classificado antes
   como não bloqueante.
2. `fases/fase-02-gradle/scripts/comparar-hash.sh:39` — se as duas pastas
   estiverem ausentes ou vazias, `total` é 0 e o script diz "0 arquivos
   comparados: todos idênticos" com exit 0. Tratar `total -eq 0` como
   problema evitaria um falso positivo. Não é o caso no repositório.
3. `fases/fase-02-gradle/scripts/comparar-hash.sh:10-14` — há um fallback
   para `sha256sum` que o `design.md` dispensava. É inofensivo, mas é um
   desvio sem registro.
4. `docs/fase-02-tutorial.md:198` e `:205` (#10, fora do escopo desta spec)
   — os hashes citados (`FileRankingRepository.java 9d5571ea2622`,
   `Mapa.java b52f60421e57`) não batem com os do checkout atual
   (`006447d827da`, `a80273838df2`). Provavelmente a saída foi gerada numa
   cópia com outra quebra de linha (CRLF). A conclusão "33 idênticos" se
   mantém. A saída desta revisão pode substituir a do tutorial.
