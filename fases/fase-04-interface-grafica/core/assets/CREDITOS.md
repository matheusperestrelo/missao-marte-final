# Créditos dos assets

Todas as imagens e sons deste jogo foram gerados por programa próprio (módulo `tools`), sem arte ou áudio de terceiros.

Para gerá-los de novo, na pasta da fase:

```
./gradlew :tools:gerarAssets
```
